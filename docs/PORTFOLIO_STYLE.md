# Стиль аналитического портфолио Алины

Версия 1. Зафиксирован на проекте Olist. Эти правила используем при переработке первого проекта и следующих работ.

## Как должен звучать текст

Коротко, спокойно и конкретно. Пишем для человека, которому нужно понять результат и выбрать следующий шаг. Используем обычные русские слова: «купили снова», «на 0,50 п.п. ниже», «три покупателя из 52». Термин добавляем, когда он точнее обычного слова, и сразу поясняем его смысл.

Главный вывод ставим в начало. Описание SQL, очистки данных и инструментов — после результатов. Если предложение можно поставить в любой аналитический проект без изменений, в нём, скорее всего, не хватает конкретики.

## Из чего складывается вывод

1. **Результат.** Кто, что сделал и за какой срок: «За 180 дней снова купили 1 358 из 49 452 покупателей — 2,75%».
2. **Сравнение.** С чем сравниваем и насколько отличается: «После опоздания — 1,37%, при доставке вовремя — 1,87%. Разница — 0,50 п.п.».
3. **Значение для решения.** Почему это важно именно здесь: «Домашний текстиль — кандидат для первого CRM-пилота: 214 повторных покупателей из 4 769».
4. **Следующий шаг.** Что именно проверить и по чему принять решение: «Сравнить предложение второй покупки с обычным сценарием; измерить повторные покупки и маржу».

Эта последовательность задаёт логику. В отчёте она может занимать короткий абзац, подпись к графику или блок с рекомендацией; четыре одинаковых подзаголовка под каждым графиком не нужны.

## Примеры: как переписали Olist

| Было | Стало |
| --- | --- |
| Категория первой покупки связана с частотой повторов. | Среди 17 крупных категорий первые по доле повторных покупателей — сумки (4,81%) и домашний текстиль (4,49%). |
| При доставке вовремя повторные покупки встречаются чаще. | За 180 дней после получения снова купили 1,87% покупателей с доставкой вовремя и 1,37% — с опозданием. Разница — 0,50 п.п. |
| Во всех сравнениях направление различия сохраняется. | Доля ниже при опоздании во всех трёх расчётах. При равных 180 днях после получения — 1,37% против 1,87%. |
| Малые группы ограничивают выводы. | 5,77% у сумок с опозданием — три покупателя из 52. Ещё один покупатель изменил бы долю до 7,69%. |
| Начать пилот персональных предложений в крупных сегментах. | Проверить предложение второй покупки после получения заказа домашнего текстиля. Сравнить долю повторных покупателей и маржу с контрольной группой. |

## Точность формулировок

- Указываем размер группы рядом с процентом, особенно если событий мало. Число покупателей и число повторных покупателей — разные величины.
- В сравнении называем обе группы. «Ниже на 0,50 п.п.» без исходных 1,37% и 1,87% недостаточно.
- Для долей используем процентные пункты, когда вычитаем одну долю из другой. Если показываем отношение «в 3,7 раза», рядом оставляем исходные проценты.
- Ограничиваем «лидера» областью сравнения: «среди 17 категорий с ≥ 1 000 покупателей». Различаем лидерство по доле и по числу покупателей.
- Всегда подписываем начало и длину окна: «180 дней от первой покупки» или «180 дней после получения». При смене метрики явно показываем, что изменилась и выборка.
- Описание данных пишем как факт. Причину называем, когда её можно установить выбранным методом. «После опоздания доля ниже» допустимо; «опоздание уменьшило повторы на 0,50 п.п.» требует оценки причинного эффекта.
- Ограничение ставим рядом с соответствующим результатом. Для группы из 52 человек полезнее показать три события и чувствительность процента, чем повторять общее «нужны дополнительные исследования».
- Не называем отличие статистически значимым без подходящего расчёта. Порог на графике служит читаемости и не заменяет такую проверку.
- Решение привязываем к данным и к критерию успеха. Выбор сегмента для теста не означает, что тест окупится.

## Структура README и отчёта

| Блок | Что в нём должно быть |
| --- | --- |
| Название | Предмет анализа простыми словами. |
| Краткий результат | Одно главное число и 2–3 содержательных вывода. |
| Задача | Какое решение помогает принять анализ. |
| Результаты | Вывод, цифры, график и короткое пояснение. |
| Следующие действия | Конкретная проверка, нужные данные и метрика решения. |
| Данные и ограничения | Период, единица наблюдения, исключения, границы интерпретации. |
| Воспроизведение | Файлы, зависимости и команда запуска. |

Полный рейтинг, промежуточные проверки и технические детали можно вынести в раскрывающиеся блоки HTML или отдельные файлы репозитория.

## Визуальные правила

- Один главный смысл на график. Заголовок сообщает результат: «У сумок доля выше в 11 из 13 месяцев».
- Главное сравнение — крупно. Полный рейтинг — отдельным подробным графиком. Состав сокращённого сравнения и место полной таблицы подписываем.
- Синий `#3D5AFE` выделяет основной сегмент или сравнение. Оранжевый `#FF8A3D` — вторую группу, исключение или проблему. Остальные данные — серые. Значение цветов поясняем внутри графика.
- Фон — белый или очень светлый `#F3F5FB`; текст — тёмный `#17233F`. Сетка тонкая и светлая `#E4E9F2`.
- Шрифт графиков — DejaVu Sans. Для PNG шириной около 2 000 пикселей: заголовок 20 pt, подписи 11–13 pt, главное число 19–36 pt.
- Столбцы начинаются с нуля. Сильный акцент создаём цветом, подписью и размером; шкала сохраняет величину различия.
- Пишем значения прямо возле столбцов. Под долей даём «50 повторных из 1 039 покупателей».
- Для малой группы можно показать людей точками: одна точка — один покупатель. Такой приём сразу объясняет, из чего получился процент.
- PNG используем в README и отчёте, SVG сохраняем для редактирования. У каждого изображения есть содержательная текстовая подпись.

## Проверка перед публикацией

Прочитать только заголовки и первые предложения. Из них должны быть понятны результат и следующий шаг. Затем проверить, что у каждого сильного утверждения есть число, база сравнения и подходящий метод. В конце прочитать текст вслух: сложные обороты заменить обычной фразой, не теряя смысла.
